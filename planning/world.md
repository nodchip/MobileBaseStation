# 世界・勢力・通信技術

提示設定の第3〜10・12・15節を収録。仕様の未確定な接続条件や運用条件は open-questions.md で管理する。

# 3．異世界「エルディア」

エルディアは、複数の王国と都市国家が存在する中世後期程度の文明圏である。

魔法は存在するが、誰でも自由に使えるものではない。魔力を持つ者は人口の約一割で、高度な魔術を使える者はさらに少ない。

## 既存の通信手段

この世界にも遠距離通信は存在する。

| 通信手段  | 特徴                       |
| ----- | ------------------------ |
| 早馬・飛脚 | 安価だが数日から数週間かかる           |
| 伝書鳥   | 比較的速いが、天候や魔物に弱い          |
| 烽火台   | 単純な情報しか伝えられない            |
| 念話魔法  | 魔術師同士だけが利用できる            |
| 共鳴水晶  | 都市間通信が可能だが極めて高価          |
| 神託網   | 教会が管理する緊急通信網。内容を教会に把握される |
| 軍用転写陣 | 文書を送れるが、一回の使用で大量の魔石を消費する |

情報を迅速に伝えられるのは、王侯貴族、軍、教会、大商会に限られている。

そのため地方では、疫病の発生が王都へ届くころには村が全滅していることも珍しくない。領主の命令が途中で改変されたり、戦争が終わったことを知らない部隊が戦い続けたりする。

通信は便利な道具ではなく、**支配階級の権力そのもの**である。


# 4．固有能力《移動基地局車召喚》

## 初期仕様

統也が地面へ手を触れ、召喚を宣言すると、前世で災害派遣に使用していたものに似た大型車両が出現する。

正式名称は能力画面上で、

> **異界適応型緊急通信支援車両《MBCV-01》**

と表示される。

外見は大型トラックだが、異世界の環境に合わせて微妙に変化している。電子機器には魔導回路が組み込まれ、燃料、電力、魔力のいずれでも一部を代替できる。

### 基本性能

| 項目       | 初期状態                 |
| -------- | -------------------- |
| 召喚可能台数   | 1台                   |
| 再召喚      | 24時間に1回              |
| 最大通信半径   | 平地で約15km             |
| 高速データ通信圏 | 約3km                 |
| 同時接続数    | 256端末                |
| 音声同時通話   | 32回線                 |
| マスト      | 最大高25m               |
| 稼働時間     | 満充電で約12時間            |
| 車両燃料     | 軽油相当の燃料、または加工した火属性魔石 |
| バックホール   | 異空間内の「召喚者専用コア網」へ接続   |
| 耐久性      | 通常の大型車両より強いが、破壊可能    |

## 最重要の制約

この能力には**地球のインターネットへ接続する機能がない**。

検索エンジン、動画サイト、百科事典、クラウドサービスは利用できない。呼び出せるのは、車両に搭載されていた災害対応用ソフトウェア、技術文書、地図作成ツール、簡易サーバーなどに限られる。

したがって統也は、現代知識を無制限に検索して文明改革できるわけではない。

さらに、基地局車だけでは利用者がいないため、車内に積載された**二百台の耐衝撃型端末**が最初の全財産となる。

端末を失えば簡単には補充できない。


# 5．基地局車の装備

## 通信設備

車両には低周波数帯用と高周波数帯用のアンテナが搭載されている。

低周波数帯は遠くまで届くが、送れる情報量が少ない。高周波数帯は大量の情報を送れるが、森、岩山、城壁に遮られやすい。

統也は状況に応じて、次のように使い分ける。

* 遠方の偵察隊には音声と短文だけを提供する
* 村の中心部では画像や地図を共有する
* 地下迷宮では有線ケーブルや小型中継器を敷設する
* 山間部では尾根に中継端末を置く
* 戦場では通信量を制限し、指揮系統を優先する

能力は万能な「念話」ではなく、地形、距離、遮蔽物、混雑の影響を受ける。

## 車載サーバー

基地局車の内部には、小規模なデータセンターに相当するサーバー設備がある。

初期状態で利用できる機能は以下のとおり。

| サービス  | 異世界での用途              |
| ----- | -------------------- |
| 音声通話  | 遠隔連絡、軍隊の指揮、医療相談      |
| 短文通信  | 命令、安否確認、商取引          |
| 一斉通知  | 魔物襲来、洪水、火災、避難命令      |
| 地図共有  | 偵察情報、道路、危険区域の記録      |
| 位置推定  | 基地局との通信状況から大まかな位置を推定 |
| 掲示板   | 村や町単位の情報交換           |
| 台帳管理  | 人口、物資、負傷者、避難者の管理     |
| 音声記録  | 証言、契約、歴史の保存          |
| 簡易翻訳  | 蓄積した対訳データを利用する統計的翻訳  |
| 暗号化通信 | 特定端末間の秘匿通話           |

GPS衛星は存在しないため、正確な位置は取得できない。複数の中継局と測量を組み合わせて、少しずつ位置情報網を構築していく。


# 6．端末の仕組み

初期端末は、画面と物理ボタンを備えた頑丈な業務用スマートフォンに近い。

ただし、識字率が低い地域でも使えるよう、能力によって操作画面が自動調整される。

文字を読めない利用者には、人物の顔、紋章、色、音声を中心とした画面が表示される。魔力を持つ者は、端末へ触れることで簡単な操作補助を受けられる。

## 端末登録

端末を利用するには、統也または認定された通信管理者が、利用者へ**通信識別紋**を発行する必要がある。

通信識別紋はSIMカードに相当し、次の情報を持つ。

* 利用者番号
* 所属する村や組織
* 通信権限
* 緊急通信の優先度
* 公開鍵
* 利用履歴の保存方針

これが後に大きな政治問題になる。

「番号を持つ者」と「番号を持たない者」の格差が生まれ、犯罪者や難民にも端末を与えるべきかが議論されるからである。

## 現地生産

初期端末二百台を使い切った後、統也は現地の錬金術師、ガラス職人、細工師と協力して簡易端末を作る。

最初に量産できるのは、画面すらない**通話専用の通信札**である。

通信札は、銅線、薄い魔石、透明度の低いガラス板、刻印回路から作られる。音質は悪く、電池も数時間しか持たないが、伝書鳥より圧倒的に速い。

この通信札が普及することで、異世界初の通信産業が誕生する。


# 7．能力の成長条件

この能力は魔物を倒しても強化されない。

成長に必要なのは、通信によって生まれた**有効接続値**である。

単純に通話回数を増やすだけでは評価されず、次のような成果で蓄積される。

* 救助要請が届き、人命が助かる
* 離れた家族が安否を確認する
* 医師の遠隔指示で患者が救われる
* 誤った命令が訂正され、戦闘が回避される
* 商人同士の情報共有で食料不足が解消される
* 災害警報によって住民が避難する
* 異なる民族の間で対話が成立する

能力の本質は「通信量」ではなく、**人と人の間に有益な関係を成立させること**にある。

一方、通信を利用して虐殺、詐欺、迫害、扇動が行われると、有効接続値が減少する場合がある。


# 8．能力の発展段階

## 第1段階：単独セル

基地局車一台と二百台の端末だけを使える。

一つの村や砦を守るには強いが、基地局車が移動すると元の地域は圏外になる。

## 第2段階：可搬型中継局

三脚式アンテナ、無線中継器、予備バッテリーを召喚できる。

山頂や塔に中継器を設置し、通信範囲を延ばせる。ただし定期的な充電と保守が必要。

## 第3段階：小型基地局

村や街へ常設できる小型基地局を製造可能になる。

ここから物語は「一台の車をどこへ置くか」から、「複数地域をどう接続するか」へ変化する。

## 第4段階：複数基地局車

二台目、三台目の基地局車が解禁される。

統也一人では運用できないため、現地の技術者を育成し、権限を委譲しなければならない。

## 第5段階：広域コアネットワーク

国境を越えた通信網を構築できる。

ローミング、番号制度、相互接続料金、犯罪捜査、通信傍受、災害時優先通信など、技術以上に政治と制度が問題になる。

## 最終段階：星界通信網

高高度気球、飛行船基地局、人工的な中継天体を利用し、大陸全体を覆う。

ただし最終的な力は、統也だけが管理する中央集権型ネットワークではない。

各国、各都市、各民族が自分たちの設備を管理しながら、共通規格によって接続する**分散型ネットワーク**となる。


# 9．基地局車が強い理由

基地局車は攻撃兵器ではないが、戦争や災害において圧倒的な効果を持つ。

## 戦闘での活用

斥候が敵を発見した瞬間、その位置が全部隊へ共有される。伝令を待つ必要がないため、敵より数倍速く部隊を動かせる。

負傷兵の状態を音声や画像で後方の治療師へ送り、応急処置の指示を受けられる。

複数の魔術師が離れた場所から詠唱のタイミングを合わせ、従来は不可能だった広域魔法を発動できる。

夜襲では見張り役が無言の警報を送り、敵に気付かれず全員を起こせる。

## 行政での活用

各村の穀物量や病人の数を毎日集計できるため、飢饉や疫病の兆候を早期に把握できる。

税の徴収記録を中央と地方で照合し、役人による横領を減らせる。

領主の命令を音声付きで配信し、途中で内容を書き換えられることを防ぐ。

## 商業での活用

離れた町の相場を確認できるため、価格差を悪用する一部商人の独占が崩れる。

荷馬車の到着予定や街道の危険情報を共有し、物流効率が大幅に向上する。

即時に契約を確認できるため、信用取引や遠隔送金が発展する。


# 10．能力の弱点

物語を成立させるため、明確な弱点を設ける。

## 電源が必要

車両は召喚できても、燃料と電力は無限ではない。

初期の燃料タンクで連続稼働できるのは約三日。以降は現地で燃料を調達するか、火属性魔石を加工しなければならない。

通信が重要になるほど、薪、油、魔石、発電要員の確保が大問題になる。

## 容量に限界がある

利用者が増えると、通信が混雑する。

祭りの日、災害時、戦争開始時には回線が集中し、「つながらない」という苦情が殺到する。

統也は音声通話を制限し、緊急通信を優先するが、一般利用者からは特権階級を優遇していると批判される。

## 基地局車が狙われる

敵も通信の重要性を理解するようになる。

基地局車への奇襲、アンテナの破壊、燃料庫への放火、技術者の誘拐が行われる。

主人公は車両を守るだけでなく、車両を失っても通信が続くネットワークを作らなければならない。

## 妨害される

雷魔法、幻術、魔力嵐は電波へ干渉する。

後半では敵国が**妨害魔導機**を開発し、通信を意図的に遮断する。統也は周波数変更、指向性アンテナ、暗号化、冗長経路で対抗する。

## 情報が正しいとは限らない

通信が速くなっても、内容が真実になるわけではない。

虚偽の魔物情報、偽の避難命令、なりすまし、切り取られた音声、扇動的な噂が瞬時に拡散する。

物語後半では、「つなげること」よりも「何を信じるか」のほうが難しい問題になる。


# 12．通信を巡る勢力

## 王国政府

軍事、徴税、治安維持への利用を望む。全国民の通信履歴を保存しようとする。

## 商業連盟

相場情報と遠隔契約を歓迎する一方、通信事業の独占権を求める。

## 神聖教会

既存の神託網を脅かされる。内部で排斥派と共存派に分裂する。

## 魔術師ギルド

基地局網を利用すれば遠隔共同詠唱が可能になるため、研究用途として高く評価する。しかし通信技術を魔術師だけで管理しようとする。

## 辺境共同体

最も大きな恩恵を受ける人々。中央政府から距離があるため、自治型ネットワークを望む。

## 無番号民

戸籍も所属も持たない難民、獣人、遊牧民、犯罪者など。

公的な通信識別紋を発行されない彼らが、独自の非公式ネットワークを作り始める。
