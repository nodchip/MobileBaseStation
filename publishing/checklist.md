# 各話の投稿チェック

これはチェック項目の原本。各話の実施結果は progress.md のメモまたはリンク先に記録する。

- [ ] 話数、所属章、話タイトル、投稿対象の本文が一致している。
- [ ] 最新本文がLunaの二段階レビューを完了し、全重要度の指摘と未確認範囲がゼロである。
- [ ] 現在の本文のSHA-256が最終レビュー記録と一致する。
- [ ] 設定・継続性・進捗が本文と整合している。
- [ ] 文頭が `第N話『話タイトル』` の形式で、progress.md と一致し、次に空行を1行挟んでいる。
- [ ] 本文に作者用メモ・レビュー記録が混入していない。
- [ ] 作品紹介やタグなど、今回必要な投稿情報が準備されている。
- [ ] 投稿画面で本文・タイトル・公開設定を確認し、プレビューで改行・ルビ等を確認した。
- [ ] 投稿後、公開状態・本文・順序を確認し、公開日時とURLを記録した。

レビュー合格だけでは投稿準備完了や公開済みとしない。投稿画面にアクセスできない場合は、その確認を未実施として残す。
